# 温湿度计 · 网页版（Web Bluetooth）

浏览器直连米家 LYWSD02，本地读数、校时、存历史、看曲线。**无需安装、无需服务器**。

## 用法

1. 用 **Chrome / Edge** 打开页面（手机安卓版也可以）
2. 点「连接温湿度计」，选中 `LYWSD02`
3. 设备开始推读数，曲线自动累积
4. 需要校时就点「校准设备时间」

## 说明

- 数据存在**浏览器 IndexedDB**里，不上传任何服务器；换浏览器/清缓存就没了，可导出 CSV 备份
- 关闭页面后不再采集（静态托管的限制）；要 7×24 采集请用桌面版
- 校时写的是 **UTC epoch + 时区**，与设备固件约定一致（写本地时间会让屏幕时间多出时区偏移）

## 协议

| 用途 | UUID | 格式 |
|---|---|---|
| 读温湿度 | `ebe0ccc1` | int16 LE 温度×100 + uint8 湿度 |
| 校时 | `ebe0ccb7` | uint32 LE UTC + int8 时区小时 |
